# AVIF conformance assets

Reference files for `Av1ConformanceDecodeTests`, `AvifCicpTests`, `AvifMetadataTests`, `AvifTransformTests` and `AvifContainerTests`.

| Files | Origin |
|---|---|
| `libavif_*_qm_dq*.avif`, `libavif_10bit_420_*.avif`, `libavif_*_tiles*.avif`, `libaom_*.avif` | Encoded for these tests with libavif 1.4.2 / libaom defaults (quantizer matrices, delta-q, delta-lf) |
| `libavif_icc_lab_alpha.avif`, `libavif_exif_xmp.avif` | Encoded for these tests with Pillow 12.1 (libavif 1.3.0) carrying an ICC profile / Exif + XMP |
| `libavif_abc_color_irot_alpha_irot.avif`, `libavif_abc_color_irot_alpha_NOirot.avif`, `libavif_clop_irot_imor.avif`, `libavif_clap_irot_imir_non_essential.avif`, `libavif_sofa_grid1x5_420*.avif`, `libavif_draw_points_idat*.avif`, `libavif_color_grid_alpha_nogrid.avif`, `libavif_paris_icc_exif_xmp.avif` | Copied unchanged from libavif's `tests/data` (BSD 2-Clause, Copyright 2019 Joe Drago; see https://github.com/AOMediaCodec/libavif/blob/main/LICENSE) |
| `libavif_prog_*.avif`, `libavif_layered3_8_444.avif` | Encoded for these tests with avifenc 1.4.2 (aom 3.14.1) `--progressive` / `--layered` (`--scaling-mode` 1/4, 1/2, 1/1); references from avifdec `--progressive --index` and dav1d `--alllayers 0` |
| `colors-animated-8bpc.avif`, `colors-animated-8bpc-alpha-exif-xmp.avif`, `colors-animated-12bpc-keyframes-0-2-3.avif` | Animated AVIF (image sequences) copied unchanged from libavif's `tests/data` (BSD 2-Clause, as above); per-track golden MD5s from dav1d on the track samples, RGB references from avifdec `--index` |
| `libavif_anim_8_444_alpha.avif` | 5-frame 96x64 4:4:4 sequence with an alpha track (timescale 30, duration 3, repetition 2), encoded for these tests with avifenc 1.4.2 (aom 3.14.1); same references |
| `libaom_inter_*.obu` | Raw AV1 (Section 5) encoded for these tests with ffmpeg + libaom 3.12.1 (`-lag-in-frames 16`, `-aom-params` enabling inter-intra, masked / distance-weighted / one-sided compound, wedges, dual filter, global and warped motion); golden MD5s of every shown frame from libdav1d |
| `libaom_seg_*.obu`, `libaom_inter_tiles_2x2.obu`, `libaom_inter_mono.obu`, `libaom_resize_*.obu`, `libaom_superres_*.obu`, `libaom_sframe.obu` | Raw AV1 encoded for these tests with ffmpeg + libaom 3.12.1 (aq-mode, tiles, gray) or aomenc built from libaom 3.15 source (`--resize-mode`, `--superres-mode`, `--error-resilient --sframe-dist`, `--aq-mode=1`); golden MD5s of every shown frame from libdav1d |
| `libaom_fg_*.avif` | Encoded for these tests with ffmpeg (2025-05 build) + libaom (`-aom-params film-grain-test=N` test vectors, or `-denoise-noise-level` estimated grain); golden MD5s from libdav1d with and without grain |
| `sharpimage_*.avif` | Produced by SharpImage's own AV1 encoder; golden MD5s come from ffmpeg/libdav1d; `sharpimage_8bit_420_premultiplied.avif` ('prem' alpha) is checked against libavif 1.3's RGBA output instead; `sharpimage_fg_*` carry film grain (libaom test vectors) and are checked against libdav1d with and without grain; `sharpimage_prog_*` are progressive (AvifEncodeOptions.Progressive), checked against avifdec `--progressive --index` and dav1d; `sharpimage_seq_*` are animated (HeifCoder.EncodeAvifSequence), checked per track against dav1d and per frame against avifdec `--index` |
| `libavif_seine_*gainmap*.avif`, `libavif_color_*gainmap*.avif`, `libavif_*supported_gainmap_*.avif` | Gain map (ISO 21496-1 'tmap') files copied unchanged from libavif's `tests/data` (BSD 2-Clause, as above); gain map pixel references from `avifgainmaputil extractgainmap` (libavif 1.4.2), accept/ignore/reject expectations from libavif's `avifgainmaptest.cc`; tone-mapped references from `avifgainmaputil tonemap` (Y4M, identity matrix, 4:4:4 = libavif's exact RGB) and CLLI from `avifImageApplyGainMap` |
| `libavif_seine_tonemapped_*.avif` | Alternate images for gain map computation, made for these tests with `avifgainmaputil tonemap -q 100` (libavif 1.4.2) from `libavif_seine_*_gainmap_srgb.avif` (PQ at headroom 1.3, BT.2020 PQ 10-bit, sRGB at headroom 0); expected gain map metadata and pixels come from `avifgainmaputil combine --qgain-map 100` on the same inputs |
| `libavif_prem_10bit_444.avif`, `libavif_prem_12bit_444.avif`, `libavif_prem_10bit_444_grid3x2.avif` | Premultiplied alpha at high bit depth (4:4:4, one as a 3x2 grid), encoded for these tests with avifenc 1.4.2 (aom 3.14.1) `--premultiply -d 10/12 [--grid 3x2]`; references are avifdec's 16-bit RGBA output |
